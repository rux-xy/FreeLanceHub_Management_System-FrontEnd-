
# Unifreelancer / FreeLanceHub Frontend

This is the frontend of a freelance management system built with React, TypeScript, Vite, Tailwind CSS, React Router, Axios, and Framer Motion.

## Features
- User login and registration
- Role-based routing
- Client job posting
- Freelancer job browsing and proposal submission
- Contract management
- Chat and notifications
- Payment status pages
- Admin dashboard

## Tech Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Axios
- React Router
- Framer Motion

## Run Locally
npm install
npm run dev

## Build
npm run build
